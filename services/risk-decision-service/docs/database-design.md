# risk_decision_trace

# Purpose

Stores complete fraud evaluation results generated by the orchestration pipeline.

This table acts as the primary audit-safe transaction trace table.

---

# Table Structure

| Column | Type | Constraints | Description |
|---|---|---|---|
| id | BIGINT | PRIMARY KEY | Internal trace identifier |
| transaction_id | VARCHAR(255) | UNIQUE, NOT NULL | External transaction identifier |
| final_status | ENUM | NOT NULL | Final fraud decision |
| ml_probability | DOUBLE | NULLABLE | ML fraud probability score |
| model_name | VARCHAR(255) | NULLABLE | ML model name |
| model_version | VARCHAR(255) | NULLABLE | ML model version |
| policy_version | VARCHAR(255) | NULLABLE | Decision policy version |
| trained_at | VARCHAR(255) | NULLABLE | ML model training timestamp |
| evaluated_at | DATETIME(6) | NOT NULL | Evaluation timestamp |

---

# Final Status Enum

```text
APPROVED
DECLINED
INITIATED
REVIEW
```

# Purpose of ML Metadata

| Field | Purpose |
|---|---|

# risk_decision_reason

# Purpose

Stores explainable decision reason codes associated with a transaction trace.

Enables:

- audit explainability
- fraud investigation
- compliance traceability
- debugging support

---

# Table Structure

| Column | Type | Constraints | Description |
|---|---|---|---|
| trace_id | BIGINT | FOREIGN KEY | Associated trace identifier |
| reason_code | VARCHAR(255) | NULLABLE | Decision explanation code |

---

# Relationship

```text
One risk_decision_trace
            |
            | 1 : N
            |
Many risk_decision_reason
```

# user_device_history

# Purpose

Stores historical user-device associations for behavioral fraud analysis.

Used for:

- new device detection
- device familiarity scoring
- behavioral anomaly analysis

---

# Table Structure

| Column | Type | Constraints | Description |
|---|---|---|---|
| id | BIGINT | PRIMARY KEY | Internal identifier |
| user_id | VARCHAR(255) | INDEXED | User identifier |
| device_id | VARCHAR(255) | NULLABLE | Device identifier |
| first_seen_at | DATETIME(6) | NULLABLE | First observed timestamp |
| last_seen_at | DATETIME(6) | NULLABLE | Most recent observed timestamp |
